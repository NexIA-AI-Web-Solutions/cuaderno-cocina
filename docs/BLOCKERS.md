# Bloqueos y pendientes

No bloquear el desarrollo sintético por ausencia de información comercial no esencial.

| ID | Área | Estado inicial | Resolución necesaria |
|---|---|---|---|
| E01 | Modelos y cliente Codex | Pendiente de preflight | Verificar disponibilidad real y routing |
| E02 | Programa antiguo | Externo pendiente | Nombre, muestra exportada y autorización |
| E03 | iPad físico | Externo pendiente | Modelo/versión y prueba real |
| E04 | Producción | Externo pendiente | Dominio, servidor, acceso y autorización |
| E05 | Copia externa | Externo pendiente | Destino cifrado autorizado y credenciales |

No presentar pendientes como fallos resueltos. Cada bloqueo nuevo incluye reproducción, alcance afectado y qué trabajo puede continuar.
