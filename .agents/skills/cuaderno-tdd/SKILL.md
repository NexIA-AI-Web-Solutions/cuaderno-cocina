# cuaderno-tdd

1. Leer docs/06-TDD-QUALITY.md y el contrato exacto de la tarea.
2. Escribir ejemplo pequeño con resultado esperado independiente; ejecutar RED semántico y guardar el fallo.
3. Implementar mínimo, GREEN y refactor. Reejecutar pruebas después del refactor.
4. Casos adversariales: desconocidos, cero, negativos, duplicados, concurrencia y permisos.
5. No test.skip, passWithNoTests, mocks de toda la DB o cambios del oráculo para acomodar un bug.
6. Entregar comandos, códigos de salida y pruebas no ejecutadas como NOT_RUN.

## Entrega

Resumen de cambios o hallazgos, archivos concretos, comandos ejecutados, códigos de salida, evidencia y límites. Las instrucciones de esta skill no conceden permisos extra ni sustituyen las capacidades reales del cliente.
