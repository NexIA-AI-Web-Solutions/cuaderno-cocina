# Datos de ejemplo

Todos los datos son ficticios. `canonical-v1.json` contiene un recetario mínimo; la clave `expectedForFixtureOnly` es un oráculo de tests que no se importa como dato de negocio. `ingredients.csv` es una entrada alternativa, no un tercer producto basado en hojas de cálculo.

El importador de producción debe implementar un esquema versionado estricto, excluir el oráculo y validar todas las referencias. Estas muestras no autorizan extraer datos de ningún programa del cliente.
